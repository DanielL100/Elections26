# Elections26

## קישור לאתר
האתר רץ בכתובת: [https://daniell100.github.io/Elections26/](https://daniell100.github.io/Elections26/)

## איך מריצים?
לצורך הרצה יש לשנות בקובץ config.js את:
1. כתובת אתר ההצבעה ממנו נשלפים הנתונים
2. המפלגה שמשמאלה יהיה הסמן האדום בברירת מחדל
3. הגוש שאליו ישוייכו מלפגות שאין להן שיוך
4. הסכמי עודפים על סמך האותיות של המפלגות
5. שמות הבלוקים וה-id שלהם
6. המפלגות שיופיעו בפס המפלגות - אות ייצוג בקלפי, אות ייצוג באתר (אין לה משמעות), שם המפלגה ושיוך לבלוק

בנוסף, האתר עושה cron job  לכאורה כל 15 דקות לאתר שבחרנו לשלוף ממנו נתונים. בפועל אפשר ללכת לעמוד Actions ולהריץ ידנית את `Run Election Data Scraper` בשביל למשוך את הנתונים העדכניים.

## תיעוד האתר
### קבצי ה-HTML
#### index.html
זהו העמוד הראשי של האתר.  
בראש העמוד יש מקום ששמור לתפריט של האתר שנטען מהקובץ `layout.js` במבנה `navbar-container`.  
לאחר מכן יש מקום לתכון הדף במבנה `container`. במבנה זה יש כמה תתי מבנים:
1. המבנה `prev_overflow` שמכיל את גרף המפלגות העליון בו ניתן לסדר את המפלגות שעברו את אחוז החסימה ועתידות להיות חלק מהכנסת.
2. הכותרת `h2` של "רשימת המפלגות".
3. המבנה `refToElecWeb` שמכיל את הקישור לאתר ועדת הבחירות ואת זמן העדכון האחרון של האתר.
4. הטבלה `general_info_border` שמכילה מידע כללי על הקולות - מספר הקולות הכשרים, מספר הקולות ששווים מנדט, שיעור ההצבעה שנספר/סופי, מספר הקולות הכשרים המבוזבזים, מספר המנדטים העודפים שנשארו לחלק על פי בדר-עופר, מקרא בנוגע לתוספת מנדט על פי בדר-עופר.
5. הטבלה `parties` שמכילה את כל המפלגות שרצות, האות שלהן, מספר הקולות שקיבלו, אחוז הקולות ומספר המנדטים לפני ואחרי בדר-עופר. בטלפון מוצגים רק שמות המפלגות, מספר הקולות ואחוז הקולות וכן מספר המנדטים הסופי לאחר בדר-עופר.
